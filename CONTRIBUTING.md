# Contributing to Dynamic Lead Scoring & Churn Engine

We welcome contributions! Please follow these steps:

1. **Fork the repository** and clone your fork locally.
2. **Create a new branch** for your feature or bug‑fix:
   ```bash
   git checkout -b my-feature
   ```
3. **Install dependencies** and set up the development environment (see the main README).
4. **Make your changes** and ensure that existing tests pass:
   ```bash
   pytest
   ```
5. **Add tests** for new functionality where appropriate.
6. **Update documentation** (README, docstrings, etc.) if you change the public API.
7. **Commit your changes** with a clear message and push to your fork.
8. **Open a Pull Request** targeting the `main` branch of the upstream repository.

### Code style
- Run `black .` and `isort .` before committing.
- Follow PEP‑8 guidelines.
- Keep imports tidy and avoid unused imports.

### Reporting bugs
- Open an issue with a clear description, steps to reproduce, and expected vs. actual behavior.

Thank you for helping make this project better!
